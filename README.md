# ASOIU Homework 2

Консольное приложение на C# для управления авиакомпаниями и авиарейсами с использованием базы данных SQLite.

Проект реализует импорт исходных данных из CSV-файлов, просмотр справочника авиакомпаний, CRUD-операции для рейсов и формирование отчётов. В качестве основной числовой характеристики рейса используется поле `distance_km`.

## Назначение проекта

Приложение предназначено для выполнения лабораторной работы по дисциплине АСОИУ. В проекте реализованы:

- работа с SQLite через пакет `Microsoft.Data.Sqlite`;
- импорт данных из CSV-файлов при первом запуске;
- объектная модель предметной области;
- редактирование данных через консольное меню;
- формирование табличных отчётов;
- использование паттерна Fluent Interface для построения отчётов.

## Структура данных

В проекте используются две связанные таблицы:

- `airline` — справочник авиакомпаний;
- `flight` — список рейсов.

Связь между таблицами:

- `flight.airline_id` -> `airline.airline_id`.

Основные поля:

- `airline_id` — идентификатор авиакомпании;
- `airline_name` — название авиакомпании;
- `flight_id` — идентификатор рейса;
- `flight_name` — название рейса;
- `distance_km` — дальность маршрута в километрах.

## Возможности приложения

После запуска пользователю доступно консольное меню:

- просмотр всех авиакомпаний;
- просмотр всех рейсов;
- добавление нового рейса;
- редактирование существующего рейса;
- удаление рейса;
- формирование отчётов.

Реализованные отчёты:

- полный список рейсов с названием авиакомпании;
- количество рейсов по авиакомпаниям;
- средняя дальность рейсов по авиакомпаниям.

## Требования

Для запуска необходимы:

- .NET SDK 10;
- операционная система с поддержкой запуска .NET-приложений.

## Сборка и запуск

Перейдите в корневую папку проекта и выполните:

```bash
dotnet build Homework-2/Homework-2.csproj
dotnet run --project Homework-2/Homework-2.csproj
```

## Как работает инициализация данных

При запуске приложение:

1. Создаёт файл базы данных `airlines.db`, если его ещё нет.
2. Создаёт таблицы `airline` и `flight`.
3. Проверяет, пусты ли таблицы.
4. Если таблицы пустые, импортирует данные из `airlines.csv` и `flights.csv`.

CSV-файлы автоматически копируются в выходную директорию проекта при сборке.

## Особенности реализации

- Для поля `DistanceKm` в модели `Flight` предусмотрена проверка: значение не может быть отрицательным.
- При добавлении и редактировании рейса проверяется существование выбранной авиакомпании.
- Отчёты формируются SQL-запросами и выводятся в табличном текстовом виде.
- Для построения отчётов используется класс `ReportBuilder`, реализующий Fluent Interface.
