## Разработка консольного приложения на C# для работы с базой данных SQLite.

## Цель работы

Освоить:

- создание консольного приложения на C#;
- работу с базой данных SQLite;
- импорт данных из CSV-файлов;
- выполнение операций добавления, просмотра, редактирования и удаления данных;
- построение отчётов по данным из базы;
- применение объектно-ориентированного подхода при разработке программы.

## Вариант

Предметная область: авиакомпании и рейсы.
Основной числовой атрибут варианта: `distance_km`.

## Постановка задачи

Необходимо разработать консольное приложение, которое:

- хранит данные в базе SQLite;
- загружает исходные данные из CSV-файлов;
- работает со справочником авиакомпаний;
- позволяет выполнять CRUD-операции для рейсов;
- формирует отчёты по данным.

## Описание предметной области

В программе используются две сущности:

- `Airline` — авиакомпания;
- `Flight` — рейс.

Между ними существует связь:

- один рейс принадлежит одной авиакомпании;
- одна авиакомпания может иметь несколько рейсов.

Структура таблиц:

### Таблица `airline`

- `airline_id` — идентификатор авиакомпании;
- `airline_name` — название авиакомпании.

### Таблица `flight`

- `flight_id` — идентификатор рейса;
- `airline_id` — идентификатор авиакомпании;
- `flight_name` — название рейса;
- `distance_km` — дальность маршрута в километрах.

## Функциональные возможности

Программа поддерживает:

- просмотр списка авиакомпаний;
- просмотр списка рейсов;
- добавление рейса;
- редактирование рейса;
- удаление рейса;
- вывод отчётов.

Реализованные отчёты:

- полный список рейсов с авиакомпаниями;
- количество рейсов по авиакомпаниям;
- средняя дальность рейсов по авиакомпаниям.


## Сборка и запуск

Из корневой папки проекта:

```bash
dotnet run --project Homework-2/Homework-2.csproj
```

После запуска пользователю отображается меню:

```text
1 - Показать все авиакомпании
2 - Показать все рейсы

4 - Редактировать рейс

```

Далее пользователь выбирает нужный пункт и работает с данными через консольный интерфейс.

## Результат

В ходе выполнения лабораторной работы разработано консольное приложение для управления авиакомпаниями и рейсами. Программа использует SQLite, поддерживает импорт исходных данных из CSV, CRUD-операции для рейсов и построение отчётов по базе данных.
